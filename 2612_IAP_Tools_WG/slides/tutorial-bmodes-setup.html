Tutorial B: UNIONS-3500 B-modes in Lightcone Studio

Clone a full A&A cosmology paper (Daley et al. 2026) with delivered data products and open the interactive viewer.

1 · Clone & launch compute 
git clone -b laptop --single-branch \
  https://github.com/cailmdaley/unions-bmodes-mystra paper-ii
cd paper-ii
lc init
lc compute launch --wait
2 · Launch viewer (Studio or Lab) 
# Lightcone Studio (live click-to-run)
npx github:LightconeResearch/ui-prototype#click-decision --run

# Public PyPI fallback: Lightcone Lab
uv tool install jupyterlab --with "jupyterlab-lightcone[full]"
jupyter-lab

Full clone (no --depth 1): lc checks commit provenance · Cℓ toggles ~13 s, pure E/B ~35 s.

  • What you get — the complete ASTRA hierarchy of UNIONS-3500 Paper II (B-mode validation for cosmic shear over 3,500 deg², accepted by A&A), with delivered harmonic-space Cℓ and real-space ξ± measurements and covariances for every catalog and PSF-leakage variant.
  • Why full clone — shallow clones break lc's commit-provenance check; --single-branch restricts the download to the laptop branch.
  • Viewer access — Lightcone Studio (--run) adds click-a-decision-option execution and a Queue inspector; if LightconeResearch/ui-prototype is not yet public on workshop morning, Lightcone Lab (jupyterlab-lightcone on PyPI) opens the same ASTRA project locally while Studio runs live on the projector.
