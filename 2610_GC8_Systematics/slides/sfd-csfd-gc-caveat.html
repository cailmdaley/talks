CSFD's galaxy null is partly by construction

  • CSFD removes an LSS template built from WISE galaxies
  • So a null against galaxies is expected, and can't by itself show CSFD keeps all real signal
  • Test it independently: shear and κ crosses, stellar/HI dust maps, mock recovery

Chiang 2023, arXiv:2306.03926 §§3–5

  • Construction — CSFD uses WISE density templates and an AKARI point-source template, constrained by SDSS galaxy/quasar tomographic correlations.
  • Why it matters — a galaxy-density null against CSFD is partly built in, so the shear, κ and CIB-route tests carry the independent weight.
Details

Euclid was not an explicitly named training set; the null is not guaranteed algebraically, and no object-level overlap was tested here. The construction nevertheless suppresses galaxy-correlated structure by design. All thirteen Cycle-2 CSFD spectrum nulls pass; some compressed means are nonzero (slide 7). References: Chiang 2023 §§3.1, 3.5, 4.2, 5.1–5.2; DES Y6 Appendix A.
