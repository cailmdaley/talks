Context is finite working memory and compaction is lossy

  • Working memory — every tool output and read file appends to the session's finite context window.
  • Compaction — when context fills, the harness summarizes earlier turns into a shorter block; nuance, exact numbers and caveats are often dropped.
  • Consequence — anything worth keeping across turns or sessions belongs in durable files (wikis, specs, git commits), not in chat history.
