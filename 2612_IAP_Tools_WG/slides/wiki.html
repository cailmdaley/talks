Searchable markdown wikis carry findings across projects

  • Why wikis — sessions start amnesiac; git-tracked, searchable markdown notes let agents retrieve prior diagnostics, decisions and failure modes instead of rediscovering them.
  • Cosmology example — extending bandpower bins to low multipoles fixed truncated mode-coupling bias in a multi-probe analysis and transferred directly into a separate cosmic shear project.
  • Discipline — rewrite notes to state what is true now rather than appending logs; keep one-line outcomes so search returns conclusions, not noise.
