Step 1: Specify and materialize flat $\Lambda$CDM

Paste into your agent

Start a new Lightcone analysis fitting flat LCDM to the Union2.1 supernova compilation to recover Omega_Lambda (H0 = 70 km/s/Mpc from the header).

Use numpy, scipy and matplotlib. Produce best_fit (JSON) and hubble_diagram (PNG, absolute + residuals). Don't add decisions yet.

https://supernova.lbl.gov/Union/figures/SCPUnion2.1_mu_vs_z.txt

What Lightcone builds

  - id: best_fit

  - id: hubble_diagram
    format: png
    inputs: [union21, best_fit]

Expected: $\Omega_\Lambda = 0.722 \pm 0.013$ ($\chi^2/\text{dof} = 0.97$)

  • What happens — the agent runs lc init, writes astra.yaml, adds numpy, scipy and matplotlib via uv add, launches a local cluster (lc compute launch --wait), and materializes both outputs into results/baseline/.
  • Why numpy + scipy — installing astropy on 30 laptops over conference Wi-Fi is slow; a 5-line scipy.integrate.quad luminosity distance agrees with astropy FlatLambdaCDM to 7 digits and installs in under a second.
  • Check yourself — run lc status in another terminal to see committed outputs and their git hashes.
