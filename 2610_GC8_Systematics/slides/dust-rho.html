CSFD brings $\bar\rho_{X,\mathrm{ext}}$ close to zero

  • Each colour — one extinction map used as the template; each point is a tracer’s correlation $\bar\rho_{X,\mathrm{ext}}$ with it, as on slide 5.
  • VMPZ (Planck 2013) correlates most, SFD less, CSFD least.
  • “Close to zero” — all thirteen CSFD full-spectrum null PTEs exceed 0.27; the compressed δ1 mean, 0.018 ± 0.007, is not zero.
  • Caveat — CSFD’s LSS template is built from galaxies, so a galaxy null is partly by construction.
Numbers

SFD is not zero either: its six density means span 0.041–0.058. The six VMPZ density means are 0.090, 0.086, 0.090, 0.106, 0.125 and 0.134 (visibility-corrected); the raw means are 0.093, 0.096, 0.097, 0.111, 0.130 and 0.136. The Cycle-2 visibility correction is small but not zero: reductions of 0.002–0.010 in ρ̄. The full 15-band zero-null tests use the complete Gaussian block. These are uncalibrated marginal Gaussian diagnostics, not a simultaneous family test.

What is plotted

Each curve joins bins within one tracer family; no line joins density, shear and κ. The same full-block GLS compression and fixed fiducial signal normalization are used for each dust map; denominator uncertainty is not propagated. Only Cycle 2, LensMC E and SPT-3G have this matched three-map comparison. The density maps include the delivered visibility correction, unlike the raw-density slide 5.

The CSFD caveat

CSFD’s LSS templates are built from WISE galaxies, constrained by spectroscopic galaxy/quasar correlations (Chiang 2023, arXiv:2306.03926, sections 3–5). A galaxy null is therefore partly by construction; it does not certify that every cosmological mode is preserved. The comparison motivates a controlled visibility-input swap with a mock recovery test, not an assertion that CSFD is perfect.
