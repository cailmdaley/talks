Setup: uv, Lightcone CLI, and your coding agent

1 · Install CLI 
curl -LsSf https://astral.sh/uv/install.sh | sh
uv tool install lightcone-cli==0.5.1
mkdir sn-cosmology && cd sn-cosmology
2a · Claude Code (own or tutorial key) 
export ANTHROPIC_API_KEY="sk-ant-…"
claude plugin marketplace add LightconeResearch/agent-skills
claude plugin install lightcone@lightcone-research
claude --model sonnet
2b · OpenCode (free models / Albert) 
npx skills add LightconeResearch/agent-skills \
  --skill astra --skill lightcone -g -a opencode -y
opencode
2c · Codex CLI 
codex plugin marketplace add LightconeResearch/agent-skills
codex plugin add lightcone@lightcone-research
codex

lightcone-cli bundles git-annex · offline fallback kit in tutorial handout.

  • Three agent paths — attendees with Claude Code (own account or one of Cail's tutorial API keys) or Codex get the full plugin including validate-on-save hooks; attendees carrying over OpenCode and Albert or free models from Guilhem's Tuesday session install the two portable skills via npx skills add (or copy SKILL.md into .opencode/skills/ if Node 22 is absent).
  • Git identity — lc init creates a git repository; ensure git user.name and user.email are configured.
  • Fallback — if conference Wi-Fi or API quotas stall, the tutorial handout bundles the Union2.1 data files and reference scripts plus astra.yaml so every attendee can run lc materialize local directly.
