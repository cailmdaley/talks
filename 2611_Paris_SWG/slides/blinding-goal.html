Goal: we don't have to think about blinding too much

  • We blind to avoid confirmation bias and for scientific legitimacy
  • Blinding should not get in the way of any science we need to do
  • Done well: it comes up only when we compare with others and unblind
  • Why blind — so that analysis choices are not steered, knowingly or not, by whether the answer matches expectation, and so that the result is credible to readers outside the group.
  • The constraint — the blind must not block the work the analysis needs: pipeline validation, null tests, covariance checks and comparisons of code all have to run on blinded vectors.
  • The aim — a blind applied once, where each data vector is made, so that day-to-day work never touches it. It then comes up at two moments: when blinded measurements are compared with other groups, and when deciding to unblind.
