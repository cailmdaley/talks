Public inputs for SPT-like mocks

  • Masks: Main, Summer A and B
  • Noise levels per band, T and P
  • 500 noise maps per band (D1)

Leonardo: /leonardo_work/EUHPC_E07_074/cmbx/inputs/spt/public_covariance_package (README.md)

  • What it is for — the inputs for mocks with SPT-3G's footprint and noise, for the covariance team to run a lensing reconstruction of its choice on simulated CMB, so that mocks for the κ blocks can start before SPT's own reconstructions can be shared. Every number comes from a public paper or data release; nothing derives from internal SPT products.
  • Masks — in the package, RA/Dec boxes built from the published field boundaries (HEALPix $N_\mathrm{side} = 2048$, RING, equatorial, binary and apodized), not survey pixel masks. For the Main field the public D1 release has the real pixel masks, which should be used; for the Summer fields no mask file is public until their release (announced for early 2027), so the boxes are the best public option. Overlap with the observed DR1 footprint: Main 423 deg², Summer A 948 deg², Summer B 137 deg²; Summer C has none and is left out.
  • Noise — white level, atmospheric knee and slope, and beam per band (95, 150, 220 GHz), with beam-deconvolved noise curves. The Summer lensing analysis is temperature-only, so only the Summer temperature noise matters. Summer beams are not public separately; the D1 Main beams stand in for them, which is close but not exact.
  • Public D1 release — the SPT-3G D1 Main-field release has the survey pixel masks and 500 sign-flip noise realizations per band; for Main-field mocks these are better than the package's boxes and noise model.
How this differs from constrained realizations

Constrained realizations on SPT's own lensing reconstructions of its simulations carry the real estimator, filtering and masks, and there are as many as SPT has simulations. The public route needs none of SPT's products and is not limited in number.

Drawn from the package's own files by make_cov_figures.py in the deck directory, in a hand-drawn style. Top: the Main, Summer A and Summer B box masks (ochre) over the observed Euclid DR1 wide footprint (blue: the union of DR1_R1 and DR1_R2 MER VIS tiles, 2341 deg², not an analysis mask), in an equal-area view about the south celestial pole; outlines are lightly smoothed, and the numbers are each field's overlap in deg², recomputed from the same maps. Sources
