blindspot makes the 3×2pt shifts for every statistic

  • Shift = cloelib theory at the drawn point − at the reference
  • One draw gives $C_\ell$, $\xi$ and COSEBIs
  • Tracers: shear and positions; no κ yet
  • GC spectro: same formula, its own script and draws

Validation: recover an injected shift on synthetic DR1 vectors, posterior width unchanged

  • All statistics — Martin Crocce (13 November) asked that the blindspot notebook produce the shift vectors for every photometric statistic, with the baseline galaxy bias, other nuisances at zero, the nowcast South n(z), and full-area unbinned $C_\ell$ from which each statistic is built. Felicitas Keil and Guadalupe Cañas Herrera regenerate them by 17 November.
  • κ — the notebook builds only shear and position tracers; cloelib v0.11 has a CMB-lensing tracer (CMBLensingTracer in observables/cmb.py) that it does not use.
  • Validation — for each of $C_\ell$, real space and COSEBIs, and each of 1×, 2× and 3×2pt: a chain on the noiseless synthetic vector, the same chain with one shift added, and the recovered shift compared to the injected one. Baseline chains 17 November, recovery and the decision at JC-2 on 24 November.
  • GC spectro — ported the spectroscopic notebook to a parallel, YAML-configured script (about 5 minutes against 2.5 hours); the photometric side is still the notebook.

Repository

cloe-org/blindspot (private to cloe-org members), main at bf6bcf9 (14 October 2026). Four notebooks, no package, tests or releases. The photometric notebook draws 100 points in $(\Omega_c, A_s)$ with seed 0 around $\Omega_c = 0.27$, $A_s = 2.1\times10^{-9}$, $H_0 = 67$, and computes theory with CAMB and the HMcode2020 emulator on a redshift grid to $z = 3$. The FS2 version is on branch 41; the spectroscopic script is PR #45. The selected index is kept outside the repository, so the repository alone does not reveal the shift.

What a CMBX shift with blindspot would need
  • The cloelib CMB-lensing tracer in the shift loop, for κ×shear and κ×positions. Their integrands vanish beyond the galaxy kernels, so the redshift grid to 3 suffices (inference, not tested).
  • For κκ, theory to the last-scattering surface, which CLOElib reaches with its continuation above the emulator's redshift range.
  • CMBX's own bandpower windows and CMB-lensing transfer applied to the unbinned shift, as dr1_cmbx's blinding module already does with its own theory.
  • Its own draw: blindspot gives the same parameters, distribution and theory code as 3×2pt, not 3×2pt's hidden point.
