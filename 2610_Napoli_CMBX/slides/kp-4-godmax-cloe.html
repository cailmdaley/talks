Contributor's notes

The main goal is to integrate GODMAX/Halo into Cloe as an external library for the non-linear power spectrum and baryon prescription, rather than re-coding it directly in Cloe. We will also add a toggle to match the kernels where needed. On the GODMAX side, we are finalising the Cloe-related changes and will maintain them in a dedicated Euclid branch, with the aim of submitting a PR to the original GODMAX repository. In parallel, we will open a PR to Cloe so that GODMAX can eventually be integrated into the main repository, followed by further optimisation if needed.
