VMPZ extinction is the Planck 2013 dust map

  • Planck R1.20 E(B−V) × 3.1 aλ
    VIS: AVIS = 2.108 E(B−V)
  • Identical in both cycles where both have data
  • Feeds the GC visibility (decontamination) maps

The OU-VMPZ-ID GalacticExtinction InfoMap uses the EBV column of HFI_CompMap_ThermalDustModel_2048_R1.20.fits, the Planck 2013 thermal-dust model (Planck Collaboration XI, 2014). The generator uses R_V=3.1 and VIS a=0.68, hence A_VIS=2.108 E(B−V), in magnitudes. It samples the Galactic parent at each equatorial tile-pixel centre by nearest-parent-pixel lookup, without additional smoothing or interpolation; the parent has nominal 5-arcmin resolution. The figure reads the actual NSIDE-2048 prepared arrays and masks from results/{tr1/tr1_systematics,tr1_v2/systematics}/template_bundle.tar, extracted in scratch/gc8/window-leakage/bundle{1,2}. Only the support-dependent removed monopole is restored using the audit's exact common-source mean; fluctuations and support are unchanged. Both states use the same TR1 South equatorial projection and absolute 0–0.18 mag stretch, with the upper tail saturated and marked by the colourbar extension. White means absent from the prepared support, not zero extinction. Cycle 2 fills many Cycle-1 gaps, but neither support contains the other: the audit finds 45,295 C1-only and 77,613 C2-only pixels. The 314,258 common source pixels are exactly identical; small restored-bundle differences are float32 roundoff. The maps therefore show prepared analysis support, not a claim that all white pixels are absent in the original all-sky parent.

These templates feed the offline GC visibility maps. The delivered VMPZ extinction InfoMaps are frozen for DR1; changing the offline visibility input is a separate proposal.
