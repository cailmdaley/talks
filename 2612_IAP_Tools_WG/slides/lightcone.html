Lightcone links each result to what produced it

  • Lightcone — reproducible, agent-run analysis infrastructure, shown here on the first UNIONS release (Paper II) and used for the Euclid × CMB lensing analysis: every result records the decisions, inputs and code it came from, so pipelines, mocks and comparisons can be rerun and checked when anything upstream changes.
  • On screen — Studio, its reading surface, on Paper II of the UNIONS release: the analysis decisions (catalog variant, blind, PSF-leakage correction, binning) beside the results they produce, with the lineage graph, provenance, data and bibliography a click away.
  • Live — the page is Studio running on this laptop over a clone of the analysis with its late-stage data products; where it is not running, the screenshot behind it shows.
  • Demonstration — brief 2-minute preview before Tutorial B: click one decision (fiducial_catalog → initial on fig_cl_fiducial, ~13 s) to show live provenance tracking. Before presenting, run lightcone-demo reset so local paper-ii matches origin/laptop and does not hit pre-cached universes.
