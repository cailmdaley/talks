Lightcone Research builds an open ecosystem for science

  • ASTRA: a specification of the scientific choices behind each result
  • Lightcone tools: agents run it and every artifact can be inspected

lightconeresearch.org

  • Lightcone Research — an open ecosystem for reproducible, composable, verifiable science, based at CNRS AISSAI and BIDS / UC Berkeley; Cail is a core member.
  • Two parts — ASTRA specifies the analysis and validates the specification; the Lightcone tools execute it with agents and expose the artifacts each result came from. The next slide is the Studio, live.
