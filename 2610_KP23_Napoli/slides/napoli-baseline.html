The 3×2pt proposal

  • Day 3, late session: the baseline model is Stage-III-like: one linear bias per bin, NLA with redshift evolution, magnification, n(z) mean shifts only, and one massive neutrino fixed during scale-cut validation. Cosmological parameters get uniform priors except $n_s$, whose Gaussian is 10× the Planck width. The most up-to-date $\log T_\mathrm{AGN}$ range is [7.3, 8.5]. The shear-bias prior stays as it is, Gaussian with σ = 0.01, considered pessimistic.
  • The same session recorded both identical priors and sampled parameters across probes, for the joint analysis, and sampled parameters agreed per KP at this stage; the $S_8$-vs-$A_s$ sampling basis was left open. The action table adds running the CMB with the same priors, for the $S_8$ tension.
  • Shared chain configs and scripts move from Cerberus into the CLOE GitHub organisation; whether CMBX gets a folder there is open.
  • CLOE splinter: decision to switch to $\sqrt{\ell}$ binning, with the number of bins explored in chains. $\ell_\mathrm{min} = 10$ was validated only on unmasked Flagship; the leaning is to keep 10–3000, not decided.

How the TR1 chains shown later differ

KP2-3 has not set TR1 priors. The chain profile behind the posteriors in this talk (workflow/scripts/tr1_production_chain_config.json) adopted most of the splinter's table after Napoli, each departure from its earlier choices kept as a named variant. Two differences remain. The n(z) stretch stays, $\mathcal{N}(1, 0.1)$, because on the v1.1 products the lens data pull the stretches to 0.6–0.8 and reject shift-only (variant shift_only fixes it). Magnification uses fixed measured slopes until the $\alpha$ convention is pinned. The table's $T_\mathrm{AGN}$ upper bound is 8.3; the day-3 session put the current range at [7.3, 8.5], and the chains follow the table until it is updated.

Context

These are the defaults a joint κ + 3×2pt analysis inherits, and a starting point for KP2-3's own choice. Two differ from the chains here: the n(z) model has a shift and a stretch per bin, and the binning (15 log bands, ℓ = 100–3000) has about three bands above ℓ = 1500, the resolution problem the $\sqrt{\ell}$ switch addresses. The calibration slide that follows covers the n(z) model and the first DR1 m. The chains here build on the 3×2pt choices and depart only where κ brings something in; KP2-3 has not decided.
