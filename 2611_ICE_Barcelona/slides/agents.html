Simulations are a verifiable environment for agents

  • a mock's input is known, so an agent can check its own work against it
  • scientists specify analysis requirements at a higher level
  • built and run with agents: Euclid × SPT-3G, UNIONS v2 catalog
  • Where the checking happens — against a simulation whose answer is known: input spectra recovered by the bandpower code, input cosmology recovered by the chains, an injected systematic recovered by its fit.
  • Higher-level requirements — what the analysis must recover, to what accuracy and under which systematics, rather than how each step is coded.
  • In this talk — in Cail's own work, the UNIONS v2 catalog production and the Euclid × CMB lensing data vectors, mocks and chains are built and run by coding agents, inside reproducible pipelines that record what each result came from. The rest of the talk is the science and how each piece is simulated.
