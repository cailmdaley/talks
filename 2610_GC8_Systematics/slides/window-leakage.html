Cycle 1's template window hid the high-$\ell$ signal

Same dust values · C1 errors inflated $\sim10\times$ · rewindowed C1 fails too
High-pass retains 80–120% of the coherent signal

The left solid curves show the extinction auto bandpowers through the original C1/C2 windows; dashed curves (labelled low-only) inject only physical Planck modes with $\ell\leq99$ before masking. The injection has no true science-band power, so its recovered high-ell power directly demonstrates leakage. The labelled isolated point is real: the low-only injection's first recovered science band, ell 112, is 1.58995e-5 (C1 window) and 1.60388e-5 mag² (C2 window). The two markers nearly coincide; this is not a true input science mode or an added data series. The next deconvolved band, ell 140.5, is negative in both windows (-1.32891e-6 and -1.22683e-6 mag²), breaking the dashed line on the log ordinate. It is omitted, not replaced by an artificial floor; the first positive point is retained and annotated.

At ell 2695.5, C1 preparation with the C2 window reduces the auto by 40.90, reproducing C2; changing iterations alone is negligible. C1 was already C2-type apodized over 0.15 degrees, not unapodized. Its fragmented support and taper topology amplify leakage. Common source values are identical; the left curves use the respective support means.

The right panel uses full 15-band Gaussian chi-squared divided by 15. Density is visibility-corrected in all three arms, kappa is SPT. The original C1 density arm uses the matched original-window controls c1_vis_original/g0–g5, including the same visibility mask weights as c1_vis_rewindowed/g0–g5. Their chi-squared values are 19.285, 19.076, 7.834, 15.737, 57.721 and 17.235 before division by 15. Only the template window changes between these two density arms; tracer maps/windows remain C1. The archived visibility-check crosses are not used for this arm because they omit the matched visibility mask weights. C1's original full-block kappa chi-squared is 20.064; the rewindowed value is 55.442; C2 is 57.666. The archived original uses observed template-data Wick terms; the rewindowed arm sets them to zero, as Cycle 2 does. Matched original-window controls change Gaussian errors by only a few per cent, compared with the roughly tenfold window effect. The high-ell errors fall to about 0.094 of the original-window controls. The crosses change too: this is not only an error rescaling.

The strict high-pass split keeps ell≥100 before masking and does not re-centre the high component. Its projection onto the original five-band ell>965 cross shape is 0.794–1.195 across thirteen tracers. This is the rounded 80–120% statement, not a retained-power fraction or an independent significance. Low-only contributions remain non-negligible against the original Gaussian errors, and can cancel high-only contributions. The test rules out explaining the entire correlation by ell≤99 leakage; it does not establish a clean small-scale origin. The main-slide shorthand “high-ell signal” denotes measured bands, not the true source multipoles.
