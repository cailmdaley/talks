Optional viewer: Lightcone Lab in JupyterLab

Inspect results, decisions, provenance and papers in the browser without reading raw YAML.

uv tool install jupyterlab --with "jupyterlab-lightcone[full]"
jupyter-lab

Browse into sn-cosmology/: the launcher becomes the project's Home.

  • Optional during the tutorial — the terminal agent and lc status are enough for the hands-on exercises; Lightcone Lab is optional for visual exploration afterwards.
  • JupyterHub — on a hub whose environment you cannot modify, install jupyterlab-lightcone via JupyterLab's Extension Manager (workbench-only mode).
