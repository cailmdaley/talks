Separate review catches what checks miss

Failure modes to expect

  • Silent omissions: diagonal errors used when full covariance exists
  • Weak checks: agents optimize the test instead of the physics
  • Plausible drift: invented citations, stale plots, unverified numbers
  • Core physics code still gets read by a human
  • Why separate contexts — an agent reviewing its own work inherits its own assumptions; a fresh-context reviewer (ideally a second model family) reads the code and outputs cold.
  • Failure modes named plainly — agents happily drop systematics when a simpler file is handy, pass loose unit tests with wrong physics, or cite numbers from memory. Building checks into the environment catches the first two; quote verification and reading core physics code catch the rest.
  • Bridge to Lightcone — even when every check passes, rapid iteration creates dozens of files whose provenance quickly tangles.
