  • Click-to-run — clicking a decision option in Studio (--run) creates a new universe, queues lc materialize local, swaps the figure on the exact frame it lands, and records the job's inputs, recipe and commit in Queue.
  • Agentic modification — the repo's CLAUDE.md tells any coding agent which variations can run locally (~13 s for Cℓ, ~40–65 s for pure E/B or COSEBIs) and which require cluster mocks (such as another blind or adaptive quadrature), so agents decline impossible requests in seconds instead of hacking workarounds.
  • Code edits — editing a plotting script, committing, and deleting the old output + manifest lets lc rematerialize a fresh figure tied to the new commit hash.
