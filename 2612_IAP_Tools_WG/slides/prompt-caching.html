Prompt caching governs real agent cost

  • Why caching matters — every turn re-sends the whole conversation; a warm prefix cache discounts repeated input by 10×–40×, whereas a cold cache or mid-prefix edit forces a full re-read.
  • Practical habit — keep tool lists and system prompts stable during a session, hand off to a fresh session once context grows large or goes cold, and delegate bulky exploration to sub-agents so it does not inflate the lead's prefix.
