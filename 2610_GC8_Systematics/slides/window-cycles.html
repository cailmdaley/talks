Cycle 1's fragmented window leaks dust power to high $\ell$

  • Left — the extinction map’s own power on each cycle’s template window. Same dust values; above ℓ ≈ 500 Cycle 1 keeps far more power: its fragmented window leaks low-ℓ dust power into high ℓ.
  • Right — extinction × raw δ6, $\ell C_\ell$ with Gaussian errors. Cycle 1’s leaked template power inflates its high-ℓ errors and hides the signal.
  • Consequence — Cycle 1 data put on the Cycle-2 window (not plotted) behave like Cycle 2: κ $\bar\rho$ 0.082 → 0.150 (Cycle 2: 0.182).
How we know it is leakage

A low-ℓ-only injection through each window (window-leakage/lowell.json) reproduces the high-ℓ excess directly. The Cycle-1 template auto is 40.9 times the rewindowed auto in the highest band. Both original windows are apodized over 0.15°. The rewindowing control (c1_rewindowed_g5.json) puts Cycle-1 tracer data on the Cycle-2 template window; the reverse direction was not computed.

The cycle ladder

κ $\bar\rho$: 0.0815 ± 0.0251 (C1) → 0.1504 ± 0.0238 (C1 rewindowed) → 0.1815 ± 0.0278 (C2); the window shift accounts for 69% of the rise. The change is not only error bars: the crosses and the template denominator also move. This does not establish a bias in the science vector.

What is plotted

Left: deconvolved extinction auto (mag²), log axes, each cycle on its own window. Right: ℓ times the raw δ6 cross for $\ell\gt300$ (lower ℓ is noise-dominated), with marginal Gaussian error bars; nothing is divided by errors. Rewindowed blocks use zero template-data Wick, the original ρ blocks observed Wick. No shared-map cross-cycle covariance is saved, so the cycle difference has no significance attached.
