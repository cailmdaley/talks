What we need from SPT

  • Noise bias: N0 (and the RDN0 recipe), N1, per estimator
  • Input and reconstructed κ for each simulation, matched
  • Mean field, masks, normalisation, transfer, L-range
  • Simulation cosmology, indexing and location
  • Bigger ask: reconstruct on the ACT / Planck input sims

Why

Today the Euclid side holds the SPT-3G Main winter lensing maps for each estimator and one simulated reconstruction per estimator, with no noise curve. The CMB-lensing noise in our mocks and covariance is therefore a stopgap: the observed κκ minus theory. With input and reconstructed κ for each simulation, input minus reconstruction gives noise realizations that carry the real reconstruction's structure, for the GLASS validation mocks and for Davide Luchina's FLASK numerical covariance (KP2-3), which he will extend to SPT given these products. The transfer of about 500 input + reconstruction pairs is tracked in Euclid Redmine issue #35882.

The list

  • Noise-bias curves: N0, and RDN0 curves or recipe for the data; N1; for each estimator variant used.
  • Input κ for each simulation, realization-matched to the reconstructed κ for each simulation.
  • Mean field, or confirmation that the released maps and simulations are mean-field subtracted, and on which subset.
  • Analysis and apodized masks, and the normalisation convention of the released κ; response and any Monte-Carlo correction, transfer function, L-range used.
  • Simulation fiducial cosmology, needed to calibrate lognormal simulations.
  • Realization count and indexing, and where the simulations live.
  • The data κ map variants, and κκ bandpowers with covariance if κκ is to be included.

The bigger ask

If SPT ran its reconstruction on the same input simulations as ACT DR6 and Planck PR4, the SPT × ACT × Planck × Euclid cross-covariances would follow from matched seeds.
