JC-2 fixes its distribution on 24 Nov

  • The proposal — my working stance: CMBX shifts the same parameters as the WL/3×2pt blind, drawn the same way, and computes the shifts with cloelib. The draw stays separate, as Euclid policy requires. Drawing from a posterior before the data exist means a posterior on mocks; the DR1 nowcast could inform DR1-like mocks for that.
  • Applied — 3×2pt produces one shift with the blindspot notebook and has it applied once to the data vectors on the SAS, so a notebook is enough. The CMBX vectors are not made on the SAS, so the shift has to be added where each data vector is computed, inside the pipeline; that needs cloelib called from the pipeline, not the blindspot notebook.
  • 3×2pt column — the blindspot photometric notebook as JC-2 is validating it (previous slides). Its distribution is still open: a mock WL posterior, a posterior of the probe being blinded, or uniform priors.
  • CMBX today — Redmine #31813, dr1_cmbx MR !9: uniform within ±0.1 in $\Omega_\mathrm{m}$ and ±0.075 in $S_8$ of Planck 2018, added to every spectrum when it is written.
  • What would change — the parametrisation, the distribution, the reference cosmology and the theory code. The mechanics stay: an additive theory difference applied at write time, a sealed choice.
Why the same parameters

Both blinds already move matter density and amplitude, so the change is smaller than it looks: $(\Omega_c, A_s)$ at fixed $h$, $\omega_b$, $n_s$ spans the same two directions as $(\Omega_\mathrm{m}, S_8)$. What matching buys is one description of the blind across the photometric programme: the same reference, the same theory code and the same sampling, so blinded CMBX and 3×2pt results have the same kind of offset, and a CMBX shift computed with cloelib has no theory-code mismatch with the 3×2pt shift for the same cosmology.

What it does not buy

The 3×2pt hidden point. Each key project keeps its own blind, so the shared γγ, δγ and δδ blocks of the CMBX vector would still carry a different shift from the official 3×2pt products. Comparing them while blinded is the third part of this session.

History

CMBX asked once before. In a CMBX–cloe-org group chat (16 December 2025) Margherita Lembo reported that Samuel Farrens could return 6×2pt blinded vectors given the data vectors and a ΔCℓ file including the CMBX spectra, and asked for the shift cosmology; Martin Crocce pointed to blindspot, "where all these calculations are done", and noted "The cosmologies that we sample from now are semi-arbitrary". The proposal on this slide asks only for the method, not the shift.
