Mocks reproduce a survey's observational properties

  • Top row — the stages of a weak-lensing analysis, from pixels to a shape catalog, each with what it has to get right.
  • Bottom row — the same for CMB lensing: detector timestreams, maps, and the lensing map reconstructed from them. Both rows meet in the data vectors and the likelihood.
  • Band — mocks, sometimes called digital twins: simulations that carry the survey's footprint, noise, PSF, redshift distributions and known systematics, run through every stage of the same pipeline as the data. Synthetic data, in other words.
  • Their purpose — the input of a mock is known, so each stage can be checked against it (does the pipeline recover the input spectra, the input cosmology?), and a systematic can be put in at a known amplitude to see what it does to the measurement.
