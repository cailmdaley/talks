Public inputs for SPT-like mocks

  • Masks: Main, Summer A and B
  • Noise levels per band, T and P
  • 500 noise maps per band available on Globus

Leonardo: /leonardo_work/EUHPC_E07_074/cmbx/inputs/spt/public_covariance_package (README.md)

  • What it is for — the inputs for mocks with SPT-3G's footprint and noise, for the covariance team to run a lensing reconstruction of its choice on simulated CMB, so that mocks for the κ blocks can start before SPT's own reconstructions can be shared. Every number comes from a public paper or data release; nothing derives from internal SPT products.
  • Masks — Main: the survey pixel mask of the public SPT-3G D1 release (borders only, a version with object holes is also in the package), downgraded to HEALPix $N_\mathrm{side} = 2048$; it covers 1805 deg². Summer A and B: RA/Dec boxes built from the published field boundaries, since no Summer mask file is public until that release (announced for early 2027). Overlap with the observed DR1 footprint: Main 477 deg², Summer A 948 deg², Summer B 137 deg²; Summer C has none and is left out.
  • Noise — white level, atmospheric knee and slope, and beam per band (95, 150, 220 GHz), with beam-deconvolved noise curves. The Summer lensing analysis is temperature-only, so only the Summer temperature noise matters. Summer beams are not public separately; the D1 Main beams stand in for them, which is close but not exact.
  • Public D1 release — the SPT-3G D1 Main-field release has the survey pixel masks, which are in the package, and 500 sign-flip noise realizations per band, which are not (1500 files of 1.0 GB); the package's README gives the commands to download them. For Main-field mocks they are better than the package's noise model.
How this differs from constrained realizations

Constrained realizations on SPT's own lensing reconstructions of its simulations carry the real estimator, filtering and masks, and there are as many as SPT has simulations. The public route needs none of SPT's products and is not limited in number.
